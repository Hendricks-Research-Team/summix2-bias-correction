# summix2-bias-correction


This repository contains the simulation framework, bias-correction methods, real-data evaluation, and analysis code used to investigate the effect of reference sample size on population substructure estimation with **Summix2**.


## Overview

Reference-based methods such as Summix2 estimate subgroup mixing proportions from genetic summary data by comparing observed allele frequencies with reference allele frequencies. The accuracy of these estimates depends on the quality and size of the reference populations. Many populations, particularly Indigenous American (IAM) populations, remain underrepresented in publicly available genomic resources, resulting in unequal reference sample sizes.

This repository evaluates how reference sample size affects Summix estimates through large-scale simulation studies, develops statistical bias-correction methods, and applies these methods to real genetic summary data.

## Power-law bias correction

To estimate ancestry-specific nonlinear bias-correction parameters, 100 random mixing-proportion combinations are generated from a Dirichlet distribution.

These combinations are **not** a separate simulation scenario. Instead, they are used to estimate the parameters of the model

[
\text{Bias}(N)=\frac{a}{N^{b}},
]

where:

* (a) controls the magnitude of the bias;
* (b) controls the rate at which bias decreases as reference sample size increases.

Power-law parameters are estimated separately for each reference population and summarized using the median across successful model fits.

## Simulation methodology

The simulation framework preserves the methodology described in the manuscript.

* Weighted continental reference allele frequencies are constructed from fine-scale reference populations.
* Variants with allele frequencies between 1% and 99% in at least one reference population are retained.
* Reference allele frequencies are generated by finite multinomial sampling.
* Observed allele frequencies are simulated under Hardy–Weinberg genotype probabilities.
* Summix is used to estimate continental mixing proportions.
* Bias is evaluated by comparing estimated and true mixing proportions across simulation replicates.
